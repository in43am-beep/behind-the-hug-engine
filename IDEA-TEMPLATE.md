# IDEA TEMPLATE — Behind The Hug (ESR-style, soldier-dog niche)
Every idea MUST fill every field before it enters the 4-step pipeline.

## TITLE
- Format: emotional hook, ≤ 80 chars. Note the Pattern used: P1 (number+time), P2 (question), P3 (contrast), P4 ("they said X…"), P5 (quiet statement).
- Rule: the title's promise = the longest beat of the script. No clickbait the story can't cash.

## AXES
- **A (Animal axis):** A1 senior dog / A2 working dog (K9/service/therapy) / A3 rescue / A4 puppy / A5 bonded pair / A6 stray
- **M (Mirror axis):** M1 shared visible mark / M2 shared loss / M3 shared routine / M4 shared duty / M5 role reversal (dog heals human) / M6 no mirror (organic bond)
- **H (Human axis):** H1 elderly / H2 veteran active-duty / H3 veteran retired / H4 child / H5 widow/widower / H6 handler
- **T (Twist axis):** T1 mistaken identity / T2 hidden object / T3 dog knew first / T4 second animal / T5 time twist

## HUMAN
Name, age, branch/role, 2–3 hyper-specific details (object they keep, habit, physical mark). These details become image-prompt anchors.

## ANIMAL
Name, breed, age, 2–3 hyper-specific physical identifiers (crooked tooth, floppy ear, gray muzzle pattern). These become the CHARACTER LOCK for every image.

## MIRROR
The shared wound OR shared habit between human and animal. One paragraph. This is the emotional engine — if you can't write it, the idea is weak. Pick a new one.

## ARENA DETAIL
Exact place: town, home type, the 3–4 props that recur (blue door, bus bench, letter stack). Recurring props = visual continuity = retention.

## HOOK (0–18s)
The exact opening visual + first line. Must contain: the animal, the strange behavior, the unanswered question.

## MISDIRECTION
- **Viewer assumes:** the obvious, slightly sad explanation.
- **Real:** the true mechanism (revealed at the twist). Must be believable — a vet/vet-nurse reader should nod.

## TWIST POSITION
Minute 6–8 of a 10-min video (scale: ~70% runtime). The moment the misdirection flips.

## CREDIBILITY ANCHOR (pick an UNUSED one per used-list)
- C-A1 photo with date stamp / C-A2 letter or written record / C-A3 official record (vet, shelter, department) / C-A4 witness testimony (neighbor, nurse, mailman)

## KEY VISUAL
The single thumbnail/climax image. Describe it like an image prompt: subjects, light, emotion, composition.

## SETBACK BEAT (script Part 6, ~55% runtime)
One thing goes wrong AFTER hope appears. The audience must fear the ending won't happen. Then it does.

## ENDING — 2 beats
- **Setup line:** reframes the whole story in one sentence.
- **Landing line:** quotable, shareable, ≤ 10 words. This is what gets commented.

## REVEAL SET (for used-list)
R1 scent / R2 sound / R3 sight / R4 touch / R5 routine / R6 voice — how the dog finally "knows". Rotate; never repeat the same set twice in a batch.
